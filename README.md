# Student Academic Tracker

A local-first academic dashboard for students.

## Features
- Subject-wise attendance tracking
- Overall attendance percentage
- 75% attendance alerts
- Classes-needed calculator
- Subject marks and average marks
- Assignment, exam, project, quiz and study planner
- Upcoming deadline dashboard
- Academic insights
- Responsive mobile UI
- Browser localStorage persistence

## Run
Open `index.html` directly or serve this repository with any static web server.
